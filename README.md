# 어디있지 (Eodi) — 일본 굿즈 · 국내 중고 통합검색

> **검색은 한 번, 결과는 전부.**
> **일본 굿즈를 한글로 검색합니다.** 야후옥션·메루카리는 "피규어"에 0건, "フィギュア"에 수만 건을 줍니다.
> 그 간극을 굿즈 사전으로 메우고, 한국 사용자가 못 읽는 일본어 **가품 표기**까지 짚어줍니다.
> 국내 중고마켓 네 곳 통합검색도 함께 합니다.

```
[국내 탭]  검색어 →  ┌ 번개장터 ┬ 당근마켓 ┬ 중고나라 ┬ 헬로마켓 ┐
                                                              ├→ 중복병합 → 랭킹
[일본 탭]  한글 → 굿즈사전 → 일본어 → ┌ 야후옥션(실시간) ┐        │
                                     └ 메루카리(수집)   ┘        └→ ¥ + 원화 환산
```

```
"주술회전 아크릴스탠드"  →  呪術廻戦 アクリルスタンド  →  ¥3,247 (약 28,000원) · 경매 1일 남음
```

## 빠른 시작

```bash
npm ci
npm run build:libs
npm run dev            # http://localhost:3000
```

DB 없이도 그대로 뜹니다. 연합검색이 실시간이라 DB는 캐시·인덱스 보강용입니다.

```bash
# 터미널에서 바로 검색해보기
npm run search  -w @eodi/crawler -- "아이폰16 프로 100만원 이하"
npm run search  -w @eodi/crawler -- --overseas "주술회전 아크릴스탠드"
# 각 마켓 어댑터가 살아 있는지 점검
npm run probe   -w @eodi/crawler -- "닌텐도 스위치"
```

## 저장소 구조

```
packages/core      순수 도메인 로직 — 질의해석·분류·중복병합·랭킹·필터. I/O 없음
packages/db        Postgres 스키마와 쿼리. DATABASE_URL 없으면 메모리로 대체
packages/crawler   소스 어댑터 · HTTP 게이트웨이 · 연합검색 · 검색 서비스 · CLI
apps/web           Next.js 15 App Router
scripts/smoke.mjs  릴리즈 게이트용 스모크 테스트
```

의존 방향은 `web → crawler → db → core`. core는 아무것도 의존하지 않습니다.

## 새 마켓 추가하기

`packages/crawler/src/adapters/<id>.ts` 파일 하나를 만들고 registry 에 등록하면 끝입니다. 그 외 코드는 건드리지 않습니다.

```ts
export const myAdapter: SourceAdapter = {
  id: 'hellomarket',
  label: '헬로마켓',
  enabled: true,
  async search(keyword, opts) {
    const json = await fetchJson(url)   // http.ts 를 반드시 경유 (레이트리밋·robots)
    return json.items.map(toRawListing)
  },
}
```

## 알려진 한계

- **당근마켓은 동네 단위 검색**이라 실시간으로는 선택한 한 동네만 봅니다. 전국 커버리지는 예열 크론이 쌓는 인덱스가 메웁니다.
- **게임 타이틀 판별이 부분적**입니다. 제목의 표기 단서(한글판·초한정판 등)에 의존해서, `닌텐도 스위치 아이작 리펜턴스` 처럼 게임 이름만 붙은 매물은 본체로 남습니다.
- **헬로마켓은 지역 정보를 주지 않습니다.** 없는 값을 지어내지 않고 그대로 비워 둡니다.
- **메루카리는 실시간 조회가 안 됩니다.** 검색 API 가 `401 unauthorized` 이고 검색 페이지도 서버 렌더되지 않아, 헤드리스 브라우저로 하루 2회 수집한 인덱스를 보여줍니다. 그래서 최신 매물이 몇 시간 늦을 수 있고, 화면에 "실시간 조회 미지원"으로 표시됩니다.
- **굿즈 사전에 없는 말은 검색되지 않습니다.** 캐릭터 318개를 넣었지만 여전히 빈 곳이 많습니다. 지어내는 대신 모른다고 말하고 기록해 둡니다.
- **가품 경고는 판매자의 표기를 읽는 것뿐입니다.** 표기하지 않은 가품은 잡지 못합니다. 진위 검증이 아닙니다.
- **iOS 는 홈 화면에 추가해야 알림이 켜집니다.** 앱스토어 심사는 없지만 한 단계가 더 있습니다.
- **찜 목록은 기기 간에 공유되지 않습니다.** 계정이 없기 때문이고, 그 대가로 개인정보를 갖지 않습니다.
- **해외 소스는 호스트가 1~2개라 검색이 몰리면 직렬화됩니다.** 그때는 수집해 둔 인덱스로 답하고 화면에 그 사실을 밝힙니다.

## 이름에 대해
- 사람에게 보이는 이름은 한글 **어디있지**, 라틴 표기와 도메인은 **eodizzi** 다.
- 코드·패키지 스코프(`@eodi/*`)·저장소명·`localStorage` 키는 **`eodi` 그대로** 둔다.
  사용자에게 보이지 않고, 스토리지 키를 바꾸면 찜해둔 목록이 날아가기 때문이다.
- 브랜드가 또 바뀌어도 코드를 건드릴 일이 없도록 일부러 분리해 두었다.

실제 매물 제목·가격·판매자 정보를 저장소에 담지 않습니다 —
그건 원 게시자의 글을 재배포하는 것이고, 수집 원칙에서
하지 않기로 한 일입니다.

## 책임

이 서비스는 각 중고마켓이 공개한 검색 결과를 모아 보여주는 메타 검색 서비스이며, 거래 당사자가 아닙니다.
게재 중단 요청을 받으면 `DISABLED_SOURCES` 환경변수로 해당 소스를 즉시 끕니다.
