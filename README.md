# 어디있지 (Eodi) — 일본 굿즈 · 국내 중고 통합검색

> **검색은 한 번, 결과는 전부.**
> **일본 굿즈를 한글로 검색합니다.** 야후옥션·메루카리는 "피규어"에 0건, "フィギュア"에 수만 건을 줍니다.
> 그 간극을 굿즈 사전으로 메우고, 한국 사용자가 못 읽는 일본어 **가품 표기**까지 짚어줍니다.
> 국내 중고마켓 네 곳 통합검색도 함께 합니다.

```
[국내 탭]  검색어 →  ┌ 번개장터 ┬ 당근마켓 ┬ 중고나라 ┬ 헬로마켓 ┐
                                                              ├→ 중복병합 → 랭킹
[일본 탭]  한글 → 굿즈사전 → 일본어 → ┌ 야후옥션(실시간) ┐        │
                                     └ 메루카리(수집)   ┘        └→ ¥ + 원화 환산
```

```
"주술회전 아크릴스탠드"  →  呪術廻戦 アクリルスタンド  →  ¥3,247 (약 28,000원) · 경매 1일 남음
```

## 빠른 시작

```bash
npm ci
npm run build:libs
npm run dev            # http://localhost:3000
```

DB 없이도 그대로 뜹니다. 연합검색이 실시간이라 DB는 캐시·인덱스 보강용입니다.

```bash
# 터미널에서 바로 검색해보기
npm run search  -w @eodi/crawler -- "아이폰16 프로 100만원 이하"
npm run search  -w @eodi/crawler -- --overseas "주술회전 아크릴스탠드"
# 각 마켓 어댑터가 살아 있는지 점검
npm run probe   -w @eodi/crawler -- "닌텐도 스위치"
```

## 저장소 구조

```
packages/core      순수 도메인 로직 — 질의해석·분류·중복병합·랭킹·필터. I/O 없음
packages/db        Postgres 스키마와 쿼리. DATABASE_URL 없으면 메모리로 대체
packages/crawler   소스 어댑터 · HTTP 게이트웨이 · 연합검색 · 검색 서비스 · CLI
apps/web           Next.js 15 App Router
scripts/smoke.mjs  릴리즈 게이트용 스모크 테스트
```

의존 방향은 `web → crawler → db → core`. core는 아무것도 의존하지 않습니다.

## 설계에서 중요한 결정들

**실시간 연합검색 + 캐시.** 미리 긁어둔 것만 보여주면 아무 키워드나 검색할 수 없습니다. 질의가 오면 그때 각 마켓에 동시에 물어보고, 같은 질의로 남의 서버를 반복해 때리지 않도록 10분 캐시를 앞에 둡니다.

**한 소스가 죽어도 검색은 성공한다.** 실패는 결과가 아니라 상태로 보고됩니다. 화면에 "번개장터 미응답"이 그대로 뜹니다. 전부 죽으면 우리 인덱스로 답하고 그 사실을 알립니다.

**잡글은 지우는 게 아니라 라벨링한다.** 케이스를 찾는 사람에게 케이스는 노이즈가 아닙니다. `판매글 / 액세서리 / 게임·타이틀 / 부품 / 삽니다·매입 / 대여·서비스 / 대량` 으로 나눠 기본값만 정하고, 필터로 되돌릴 수 있게 합니다.

**중복 병합은 보수적으로.** 잘못 합치는 것이 놓치는 것보다 나쁩니다. 제목 3-gram 유사도 + 가격 ±2% + 등록시각 ±3일이 모두 맞아야 묶습니다.

**당근은 동네 단위로 갈린다.** 실측 결과 지역이 다르면 결과가 0% 겹칩니다. 그래서 실시간 검색은 한 동네만 보고, 예열 크론이 여러 동네를 돌며 쌓은 인덱스로 커버리지를 넓힙니다. 화면에는 지금 어느 동네를 보고 있는지 항상 표시합니다.

**소스당 요청 1회.** 페이지를 더 넘기면 결과는 늘지만 레이트리밋 대기가 그대로 사용자 응답 지연이 됩니다. 3개 마켓을 다 뒤지고도 1.5초입니다. 깊게 파는 일은 예열 크론이 맡습니다.

**알림에 앱은 필요 없습니다.** 찜은 localStorage 라 계정도 서버 저장도 없습니다. 알림은 PWA + Web Push 라 앱스토어를 거치지 않습니다 — 안드로이드·PC 는 그냥 되고, **iOS 는 "공유 → 홈 화면에 추가" 한 번**이면 됩니다(iOS 16.4+, 앱 설치 아님). 계정을 만들지 않으니 이메일도 이름도 받지 않고, 브라우저의 푸시 구독이 곧 신원입니다.

**알림은 처음부터 쏟아붓지 않습니다.** 방금 등록한 알림이 기존 매물 30건을 한꺼번에 보내면 그건 알림이 아니라 스팸입니다. 첫 실행은 현재 목록을 기억만 하고 넘어갑니다. 대신 "며칠간 0건이다가 처음 하나 뜬" 순간은 반드시 알립니다 — 사용자가 그걸 기다린 겁니다.

**경고는 하되 보증은 하지 않습니다.** 가품·개조·예약·흠집 표기는 배지로 알려주지만, "정품 인증" 같은 긍정 배지는 만들지 않습니다. 판매자가 "정품"이라 써도 우리가 검증한 것이 아니고, 긍정 배지는 우리가 보증하는 것처럼 읽히기 때문입니다. 경고가 붙어도 결과에서 빼지 않습니다 — 개조품을 일부러 찾는 컬렉터도 있으니 순위만 낮춥니다.

**일본 굿즈는 크롤링이 아니라 사전으로 이깁니다.** 야후옥션에 "피규어"를 치면 0건, "フィギュア"를 치면 수만 건입니다. 크롤러는 누구나 붙이지만 그 간극을 메우는 사전은 검색 로그가 쌓여야 정확해집니다. 못 옮긴 말은 `untranslated_term` 에 쌓여 다음 보강 대상이 됩니다 — 쓸수록 벌어지는 자산입니다.

**국내와 일본을 한 목록에 섞지 않습니다.** 일본 매물의 표시가는 지불액이 아닙니다(구매대행 수수료·국제배송·관세). 섞으면 "일본이 훨씬 싸다"는 착각을 줍니다. 대신 탭으로 나누고, 추가 비용이 붙는다는 사실을 상단에 고정 노출합니다.

**수집은 지킬 수 있는 선까지만.** robots.txt 를 문서가 아니라 코드로 강제하고([`packages/crawler/src/robots.ts`](packages/crawler/src/robots.ts)), 호스트당 동시 1건·최소 간격을 둡니다. 로그인·우회·캡차 회피는 하지 않으며, 진짜로 막힌 소스는 비활성 상태로 두고 그 이유를 화면에 그대로 씁니다. 자세한 내용은 아래 “수집 원칙”을 보세요.

```bash

npm run prewarm  -w @eodi/crawler -- --scope=overseas --keywords=60
npm run crawl:mercari                                  # 헤드리스 브라우저 수집
npm run untranslated                                   # 굿즈 사전 보강 대상 보고

npm run maintain -w @eodi/crawler -- --listing-days=90
```

## 새 마켓 추가하기

`packages/crawler/src/adapters/<id>.ts` 파일 하나를 만들고 registry 에 등록하면 끝입니다. 그 외 코드는 건드리지 않습니다.

```ts
export const myAdapter: SourceAdapter = {
  id: 'hellomarket',
  label: '헬로마켓',
  enabled: true,
  async search(keyword, opts) {
    const json = await fetchJson(url)   // http.ts 를 반드시 경유 (레이트리밋·robots)
    return json.items.map(toRawListing)
  },
}
```

## 알려진 한계

- **당근마켓은 동네 단위 검색**이라 실시간으로는 선택한 한 동네만 봅니다. 전국 커버리지는 예열 크론이 쌓는 인덱스가 메웁니다.
- **게임 타이틀 판별이 부분적**입니다. 제목의 표기 단서(한글판·초한정판 등)에 의존해서, `닌텐도 스위치 아이작 리펜턴스` 처럼 게임 이름만 붙은 매물은 본체로 남습니다.
- **헬로마켓은 지역 정보를 주지 않습니다.** 없는 값을 지어내지 않고 그대로 비워 둡니다.
- **메루카리는 실시간 조회가 안 됩니다.** 검색 API 가 `401 unauthorized` 이고 검색 페이지도 서버 렌더되지 않아, 헤드리스 브라우저로 하루 2회 수집한 인덱스를 보여줍니다. 그래서 최신 매물이 몇 시간 늦을 수 있고, 화면에 "실시간 조회 미지원"으로 표시됩니다.
- **굿즈 사전에 없는 말은 검색되지 않습니다.** 캐릭터 94개를 넣었지만 여전히 빈 곳이 많습니다. 지어내는 대신 모른다고 말하고 기록해 둡니다.
- **가품 경고는 판매자의 표기를 읽는 것뿐입니다.** 표기하지 않은 가품은 잡지 못합니다. 진위 검증이 아닙니다.
- **iOS 는 홈 화면에 추가해야 알림이 켜집니다.** 앱스토어 심사는 없지만 한 단계가 더 있습니다.
- **찜 목록은 기기 간에 공유되지 않습니다.** 계정이 없기 때문이고, 그 대가로 개인정보를 갖지 않습니다.
- **해외 소스는 호스트가 1~2개라 검색이 몰리면 직렬화됩니다.** 그때는 수집해 둔 인덱스로 답하고 화면에 그 사실을 밝힙니다.
- **게임 타이틀 판별이 부분적**입니다. 제목의 표기 단서에 의존해 게임 이름만 붙은 매물은 본체로 남습니다.

## 이름에 대해
- 사람에게 보이는 이름은 한글 **어디있지**, 라틴 표기와 도메인은 **eodizzi** 다.
- 코드·패키지 스코프(`@eodi/*`)·저장소명·`localStorage` 키는 **`eodi` 그대로** 둔다.
  사용자에게 보이지 않고, 스토리지 키를 바꾸면 찜해둔 목록이 날아가기 때문이다.
- 브랜드가 또 바뀌어도 코드를 건드릴 일이 없도록 일부러 분리해 두었다.

## 라이선스

**소스 공개(source-available)이지 오픈소스가 아닙니다.** 자세한 내용은 [LICENSE](LICENSE) 를 보세요.

저장소가 public 인 이유는 오픈소스로 열려는 게 아니라 **인프라 제약** 때문입니다.
수집·예열·알림을 GitHub Actions 크론으로 돌리는데 실제 필요량이 월 약 6,000분이고,
private 무료 한도는 2,000분입니다. private 으로 두면 월 30달러가 넘게 들어
"운영 비용 0원"이라는 전제가 깨집니다.

- 열람·학습·인용·개인적 실행: 가능
- 이 코드로 서비스를 배포·운영하거나 상업적으로 쓰는 것: 사전 동의 필요
- 굿즈 사전(`goods.data.ts`)과 제품 카탈로그(`catalog.data.ts`) 추출: 금지

**매물 데이터는 저장소에 없습니다.** 테스트 픽스처는 전부 합성 데이터이며,
실제 매물 제목·가격·판매자 정보를 저장소에 담지 않습니다 —
그건 원 게시자의 글을 재배포하는 것이고, 수집 원칙에서
하지 않기로 한 일입니다.

## 책임

이 서비스는 각 중고마켓이 공개한 검색 결과를 모아 보여주는 메타 검색 서비스이며, 거래 당사자가 아닙니다.
게재 중단 요청을 받으면 `DISABLED_SOURCES` 환경변수로 해당 소스를 즉시 끕니다.
